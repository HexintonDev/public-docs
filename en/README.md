## Start here

* [Public user guide](start-here/public-user-guide.md)

The Hexinton Engine technical Wiki is for script authors, trainer creators, tool integrators, and AI assistants. The user guide is for people operating the installed Hexinton Mod client.

## Scope

This public repository contains usage and scripting documentation only. Internal architecture, product designs, requirements, implementation plans, and private operational notes are not part of this site.

## Evidence

The technical pages and samples are cross-checked against the ProcessEngine implementation and automated test fixtures. Source repository URLs are intentionally omitted from this public site.
